For the Anthro sim (C# headless, Anthro/ folder): everything should be structural, organic and emergent — no hard-coded events, schedules or global valuation constants; world facts grounded in real data; any hand-set number disclosed honestly. Don't commit to git unless asked. For audits the user wants findings first, then a conversation before changes.

**Why:** the user wants a believable god-sim where outcomes come from mechanisms, not scripts.

**How to apply:** prefer mechanisms with field-data parameters over tuning knobs; flag authored numbers in comments and in summaries; when the user asks for an audit, report and wait. Related: [[anthro-balance-target]].

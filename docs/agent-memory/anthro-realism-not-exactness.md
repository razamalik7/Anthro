Calibration doesn't need to hit real forager rates. Starvation or violence a bit too common is fine,
especially when it makes good game mechanics. What matters: it's realistic in kind, we fully understand
why it happens, and it emerges naturally rather than being hard-coded.

**Why:** user, 2026-10-06, after v28 showed starvation/violence above real rates: "doesnt NEED to be
exactly like foragers were for us".

**How to apply:** stop tuning numbers toward ethnographic targets for their own sake. Prioritise
explaining causes and removing hard-coding; flag only outliers that break the game or the balance
target ([[anthro-balance-target]]). Accelerated evolution is already planned, so heritable traits
(e.g. mating psychology) can become evolution paths later. Marriage v1 = learned customs only, biology
fixed ([[anthro-design-principles]]).

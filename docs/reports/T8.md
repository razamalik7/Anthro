# Task T8: Fork Nudges at Life Branch Points

## What changed
- `Anthro.Sim/People/Person.cs`:
  - Added `Nudges` dictionary (`fork -> choice`) tracking active divine inclinations.
  - Added `TryConsumeNudge(fork, out choice)`: consumes and clears the nudge so it shifts that single decision and leaves subsequent choices organic.
- `Anthro.Sim/God/God.cs`:
  - Implemented `ForkNudgeCommand.Execute`: parses fork and value (e.g., `marry:yes`, `leave:stay`, `duel:peace`, `raid:join`, or general value applied to all keys), sets the target person's nudge, and writes to Chronicle and `GodEvents`.
  - Exposed `Region.ApplyGodCommands()` for deterministic execution and testability.
- `Anthro.Sim/Family.cs`:
  - Branch Point 1 (`WouldPair`): detects pairing decisions; emits `ForkPair` god event; consumes `marry` nudge (`yes`/`pair` accepts, `no`/`refuse` rejects).
  - Branch Point 2 (`ConsiderLeaving`): detects marriage dissolution decisions; emits `ForkLeave` god event; consumes `leave` nudge (`yes`/`leave` parts ways, `no`/`stay` perseveres).
- `Anthro.Sim/Society.cs`:
  - Branch Point 3 (`DoAttack`): detects quarrel escalation to single combat; emits `ForkDuel` god event; consumes `duel` nudge (`fight`/`duel` forces single combat, `peace`/`no` averts duel).
- `Anthro.Sim/JointActs.cs`:
  - Branch Point 4 (`Joins`): detects participation in raids or rallies; emits `ForkRaid` god event; consumes `raid`/`rally` nudge (`join`/`yes` commits participant, `refuse`/`no`/`stay` declines).
- `Anthro.Tests/SimulationTests.cs`:
  - Added `ForkNudgeCanPreventOrForcePairing` verifying that divine intervention can reject or force pairing at a 10-favor cost.
  - Added `ForkNudgeCanInfluenceLeaving` verifying divine intervention forcing or averting marriage separation.
  - Full test suite passes: 30 / 30 tests pass.

## Hand-set numbers disclosed
- **Favor Cost**: 10.0 favor per `CastForkNudge` (matching `docs/GOD-LAYER.md` §4).
- **Consumption Lifetime**: One-shot consumption (`TryConsumeNudge`). The whisper guides exactly one fork choice and does not establish a persistent override.

## Switches
- `Simulation.Off("nudge")`: Disables fork nudge evaluations while leaving other god mechanics active.
- `Simulation.Off("god")`: Disables all god features globally.
- `Simulation.Off("power")`: Disables active god power execution.

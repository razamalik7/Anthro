# Task T6: Reputation, Offerings, Rites, Last Embers, and Fading

## What changed
- `Anthro.Sim/Activities/Activity.cs`:
  - Added `Verb.Offer` enum value for sacrificial food offerings.
- `Anthro.Sim/Activities/CampActivities.cs`:
  - Implemented `Offer : TimedActivity`: A believer sacrifices food rations from their household store to the god.
  - Sized by household food security; awards favor to the region pool.
  - Fear factor: if the god is perceived as cruel (`god:kind < 0`), fear multiplication `(1.0 + |kind| * 1.5)` yields increased favor.
- `Anthro.Sim/Activities/Decider.cs`:
  - Added option for `Verb.Offer` in `Decider.Options` for grown adults with sufficient household food (`daysOfFood >= 2.0`, `food >= 2.0`).
  - Score is weighted by belief (`god:real`), fear motive (`|kind| * W(Safety) * 2.5` when `kind < 0`), and devotion (`kind * 0.5` when `kind > 0`).
- `Anthro.Sim/Gatherings.cs`:
  - Added communal rites favor generation during seasonal gatherings when `lang.ritual` is known. Each participating believer adds favor to the region and reinforces communal `god:real`.
- `Anthro.Sim/God/God.cs`:
  - Implemented reputation power cost discounts: positive reputation (`Reputation > 0`) discounts blessings (`Bounty`, `BlessedBirth`) up to 30%; negative reputation discounts omens/wrath up to 30% (`Math.Max(0.7, 1.0 - |Reputation| * 0.03)`).
  - Added `SpendFavor(double amount)` helper and `GodFaded` check: when `GodFaded == true`, favor drops to 0, favor cap drops to 0, and all pending/future commands are discarded.
- `Anthro.Sim/God/Prayers.cs`:
  - Implemented Last Embers: when `Favor <= 5.0` and believer count $\le 2$, new prayers are marked `IsEmber = true`.
  - Ember resolution: if an ember prayer is answered, faith surges (+0.40) and `IgnoredEmbers` resets to 0. If unanswered/failed, `IgnoredEmbers` increments.
  - If 3 ember prayers are ignored (`IgnoredEmbers >= 3`), `GodFaded = true` triggers, clearing the favor pool and logging divine fading to the chronicle.
  - Extracted public `ResolvePrayer(Prayer, bool)` on `Region`.
- `Anthro.Sim/Social.cs`:
  - Changed `AtCamp(Person)` visibility to `internal static` so `Decider` can check camp presence.
- `Anthro.Tests/SimulationTests.cs`:
  - Added unit test `CruelGodPromptsFearOfferingsAndEarnsFavor` verifying that a believer holding `god:kind < 0` receives a fear score boost for `Verb.Offer` and sacrifices food to grant favor.
  - Added unit test `IgnoredEmbersCauseGodToFade` verifying that 3 failed ember prayers cause `region.GodFaded = true` and zero out favor.
  - Updated `PowerBountyFlourishesPlantsAndAnimals` assertion to account for the reputation discount mechanic.

## Hand-set numbers disclosed
- **Offerings** (`CampActivities.cs`, `Decider.cs`):
  - Minimum food threshold: `home.Food.Total >= 2.0 && home.DaysOfFood >= 2.0`.
  - Amount offered: up to 2.0 rations, capped at 15% of hearth food.
  - Decider weight: `real * (0.15 + fearMotive + devotionMotive)` with `fearMotive = |kind| * W(Safety) * 2.5` (when `kind < 0`) and `devotionMotive = kind * 0.5` (when `kind > 0`).
  - Favor earned: `actualFood * real * 2.5 * fearFactor` where `fearFactor = (1.0 + |kind| * 1.5)`.
- **Communal Rites** (`Gatherings.cs`):
  - When `lang.ritual` is known, each adult believer participating contributes `0.8 * real` favor (capped at FavorCap) and receives `+0.04` reinforcement to `god:real`.
- **Reputation discounts** (`God.cs`):
  - Discount rate: 3% per reputation point (`1.0 - |Reputation| * 0.03`), capped at 30% max discount (`Math.Max(0.7, ...)`).
- **Last Embers & Fading** (`Prayers.cs`):
  - Ember trigger threshold: `Favor <= 5.0 && Believers <= 2`.
  - Rekindled surge on answered ember: `+0.40` absorption toward 1.0.
  - Fading threshold: 3 consecutive failed/ignored ember prayers (`IgnoredEmbers >= 3`).

## Switches
- `Simulation.Off("offer")`: Disables offerings.
- `Simulation.Off("god")`: Disables the entire god layer.

## Surprises & Diagnostic Notes
- Because reputation shifts by +1 on blessings and -1 on wrath, consecutive blessings naturally gain compounding cost efficiency. Testing confirmed the 3% discount applies properly.
- The `HomeOf` method ensures households maintain food accounting during offerings, deducting actual rations before computing favor.

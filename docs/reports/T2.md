# Task T2 — The God Object and Powers API Report

## What Changed
- **`Anthro.Sim/God/God.cs`** (new): Extended `Region` with the divine layer state:
  - `Favor`: Current favor pool, starting at 50.0.
  - `Reputation`: Balance of kind vs. cruel acts, starting at 0.0.
  - `FavorCap`: $\sum (\text{believers' } \text{god:real}) \times k$ (with minimum buffer equal to `StartFavorPool`).
  - `GodEvents`: Audit log of divine interventions and prayer events.
  - `EnqueueGodCommand`: Queue for player/bot actions executed at the start of the next hour.
  - Power API stubs with costs: `CastOmen` (5.0), `CastBounty` (20.0 plants / 30.0 animals), `CastWeather` (60.0), `CastBlessedBirth` (40.0), `CastForkNudge` (10.0).
  - `ApplyGodCommands`: Executes pending commands deterministically at the start of each hour step.
- **`Anthro.Sim/Region.cs`**: Called `ApplyGodCommands()` at the top of `Step()`.
- **`Anthro.Tests/SimulationTests.cs`**: Added `GodApiInitializesAndExecutesCommandsDeterministically` unit test. 17/17 tests passing.

## Disclosed Numbers & Parameters
- **Starting favor pool**: 50.0.
- **Favor cap factor $k$**: 10.0 per unit of active belief.
- **Power costs (placeholders from GOD-LAYER §4)**:
  - Omen: 5.0
  - Bounty: 20.0 (plants), 30.0 (animals)
  - Weather: 60.0
  - Blessed Birth: 40.0
  - Fork Nudge: 10.0

## Ablation Switches
- `Simulation.Off("god")`: Bypasses divine command queue execution and clears pending commands.
